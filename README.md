# 🛡️ CyberShield 2026 - CTF Registration Form

A responsive and semantic HTML5 registration form built for a campus Capture The Flag (CTF) cybersecurity event.

📌 **Live Demo:** [Click here to view live site](https://radhaanu28.github.io/ctf_registration/)

---

## ✨ Features
* **Semantic HTML structure** (`<form>`, `<fieldset>`, `<legend>`, `<label>`, `<input>`)
* Built-in client-side validation (required fields, email formats)
* Accessible labels and structured input fields
* Mobile-friendly layout

## 🛠️ Tech Stack
* **HTML5**
* Hosted via **GitHub Pages**
